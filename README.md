# Олимп Агро — сайт (папка `site/`)

Статический сайт ООО «Олимп Агро» (запчасти к сельхозтехнике, Ставрополь).
Тексты — из `../sources/`, без выдуманных фактов о бизнесе. Бэкенда нет:
открывается как есть на любом статическом хостинге.

## Структура

```
site/
├── index.html                    Главная                      /
├── o-kompanii/index.html         О компании                   /o-kompanii/
├── zapchasi/index.html           Запчасти и подбор + форма     /zapchasi/
├── kak-my-rabotaem/index.html    Как мы работаем               /kak-my-rabotaem/
├── dostavka-i-oplata/index.html  Доставка и оплата + FAQ       /dostavka-i-oplata/
├── kontakty/index.html           Контакты, карта, реквизиты    /kontakty/
├── 404.html                      Страница «не найдено» (корневые пути /…)
├── assets/
│   ├── css/styles.css            дизайн-система, адаптив, печать
│   ├── js/main.js                меню, аккордеоны, форма, мессенджеры
│   └── img/photos/               combine.jpg, equipment.jpg
├── favicon/
│   ├── favicon.svg               векторный знак (шестерня + лист)
│   ├── favicon.ico               16/32/48/64
│   ├── favicon-32.png / -48.png / -192.png
│   └── apple-touch-icon.png      180×180, на белой подложке
├── robots.txt                    работает сразу, Sitemap — закомментирована
├── sitemap.xml.example           шаблон: переименовать + подставить домен
└── README.md                     этот файл
```

Страницы лежат папками с `index.html` — адреса получаются без `.html`:
`домен/zapchasi/`. Внутри разделов пути к ресурсам относительные (`../assets/…`),
поэтому сайт работает и с подпапкой хостинга (`/podkatolog/site/`), и по домену.

## Посмотрить локально

```powershell
cd site
python -m http.server 8000
# http://127.0.0.1:8000/            — главная
# http://127.0.0.1:8000/zapchasi/   — разделы по папкам
```

Двойной клик по `index.html` тоже работает (только без шрифта Golos Text, карты
и favicon- PNG из-за `file://`). Для страниц в подпапках открывайте
`o-kompanii/index.html` и т. п.

## Проверка целостности

После любой правки текстов, ссылок или переезда разделов:

```powershell
python ..\tools\check_links.py
```

Проверяет: локальные ссылки и файлы по ним, якоря, незакрытые теги, один `h1`
на странице, `lang="ru"`, длину Title (10–60) и Description (40–160), отсутствие
ссылок на старые `.html`, разрешимость `image`/`url` в JSON-LD, а также файлы,
на которые никто не ссылается. Код выхода 0 — всё в порядке.

## Что работает на страницах

- **Адаптив:** 5 колонок преимуществ на десктопе, меню-«гамбургер» ниже 1120 px,
  одна колонка на мобильных; плавающая кнопка «Позвонить»; `@media print`.
- **Аккордеоны** FAQ и «частых запросов» на `aria-expanded`; при выключенном JS
  панели просто остаются раскрытыми (тексты не теряются).
- **Формы** (`/zapchasi/`, `/kontakty/`): без обработчика — по submit собирается
  письмо на `maxagro2014@yandex.ru` с темой и заполненными полями, текст
  дополнительно кладется в буфер обмена, рядом показывается подсказка позвонить.
  Обязательные поля: имя, телефон, марка и модель техники (на «Контактах» —
  имя, телефон, «что требуется»).
- **Мессенджеры:** ссылки `wa.me/79624474717` и `t.me/+79624474717` строятся из
  телефона в `assets/js/main.js`; туда же уходит предзаполненный текст запроса.
  Фото детали приложить к `mailto:` нельзя — для фото и служит мессенджер.
- **Карта** на контактах — iframe виджета «Яндекс Карт» по строке поиска адреса
  (координаты не задавались: их нет в исходниках) + ссылка «Открыть в Яндекс.Картах».
- **Разметка Schema.org:** `Store` на главной, `ContactPage` + `Store` на контактах
  (телефон, e-mail, адрес, график 8:00–18:00 ежедневно).

## Настройка после привязки домена

1. `canonical` на 7 страницах помечен `<!-- TODO: после привязки домена … -->` —
   заменить на абсолютные (`https://домен/zapchasi/`) и добавить `og:url`,
   сделать `og:image` абсолютным.
2. `sitemap.xml.example` → переименовать в `sitemap.xml`, заменить домен (6 раз),
   раскомментировать `Sitemap:` в `robots.txt`.
3. Подключить `404.html` на хостинге:
   - **Apache / cPanel:** `ErrorDocument 404 /404.html` в `.htaccess`;
   - **nginx:** `error_page 404 = /404.html;`;
   - **GitHub/GitLab Pages:** файл `/404.html` подхватывается автоматически;
   - **Cloudflare Pages / S3:** указать `404.html` в настройках.
   Внутри `404.html` пути корневые (`/assets/...`), поэтому страница отдаётся
   корректно для любого несуществующего адреса.
4. Если нужна настоящая отправка писем с вложением фото — подключить обработчик
   формы (Formspree, свой PHP и т. п.) и заменить обработчик submit в
   `assets/js/main.js`.
5. При появлении оригинального логотипа — заменить `favicon/favicon.svg` и
   перегенерировать PNG/ICO; в шапке и подвале знак нарисован инлайновым SVG
   (упрощённое воспроизведение печати).
