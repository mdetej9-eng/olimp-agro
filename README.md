# Сайт ООО «Олимп Агро» — запчасти к сельхозтехнике, Ставрополь

Статический многостраничный сайт: подбор и поставка запчастей к сельхозтехнике.
Сборка не нужна — в репозитории лежит готовая к отдаче статика.

## Структура

```
/                        Главная
/o-kompanii/             О компании
/zapchasi/               Запчасти и подбор + форма запроса
/kak-my-rabotaem/        Как мы работаем (5 шагов)
/dostavka-i-oplata/      Доставка и оплата + FAQ
/kontakty/               Контакты, карта, реквизиты
404.html                 Страница «не найдено»
assets/css/styles.css    Дизайн-система, адаптив, стили печати
assets/js/main.js        Меню, аккордеоны, форма, ссылки в мессенджеры
assets/img/photos/       Фотографии техники из карточки организации
favicon/                 favicon.svg, .ico, PNG 32/48/192, apple-touch-icon
robots.txt               Работает как есть
sitemap.xml.example      Шаблон карты сайта (см. «После привязки домена»)
.nojekyll                Отключает обработку Jekyll на GitHub Pages
```

Разделы — папки с `index.html`, поэтому адреса без `.html`. Пути к ресурсам
относительные, сайт работает и в корне домена, и в подпапке.

## Локальный просмотр

```bash
cd <папка репозитория>
python3 -m http.server 8000
# http://127.0.0.1:8000/
```

## Публикация на GitHub Pages

1. **Settings → Pages → Source: Deploy from a branch → `main` / `Root`** — файл
   `.nojekyll` уже отключает Jekyll, ничего больше настраивать не нужно.
2. Сайт станет доступен по адресу вида `https://<аккаунт>.github.io/<репозиторий>/`.
3. Для своего домена: **Settings → Pages → Custom domain**, затем на стороне DNS —
   `A`-записи GitHub и `CNAME`. После этого адреса станут `https://домен/zapchasi/`.

Про `404.html`: она отдаётся для любого несуществующего адреса, поэтому глубина
URL неизвестна и относительные пути к ней не применимы. Страница сама вычисляет
корень сайта по имени хоста: на `*.github.io` добавляется префикс репозитория
(`/olimp-agro/assets/…`), на собственном домене пути остаются от корня. Поэтому
оформление и ссылки на 404 работают при обоих вариантах размещения; если
JavaScript отключён, страница откроется без стилей (запасной `<link>` в `<noscript>`
рассчитан на корень домена).

## После привязки домена

1. На всех страницах заменить относительные `<link rel="canonical">` на абсолютные
   (помечено комментариями `<!-- TODO: после привязки домена … -->`) и добавить `og:url`.
2. `og:image` сделать абсолютным (`https://домен/assets/img/photos/combine.jpg`).
3. `sitemap.xml.example` → переименовать в `sitemap.xml`, подставить домен,
   раскомментировать строку `Sitemap:` в `robots.txt`.

## Что нужно сверить перед публикацией

- **Реквизиты** (ИНН, ОГРН, юр. адрес, e-mail) взяты с печати организации;
  цифру ОГРН на фото частично перекрыт блик — сверить с ЕГРЮЛ.
- **Адрес приёма** (2-й Юго-Западный проезд, 3а, офис 16) и **юридический адрес**
  (1-й Параллельный проезд, 8, офис 402) различаются — на сайте показаны оба
  с пометкой «уточните по телефону».
- **Группы запчастей** на `/zapchasi/` — ориентировочный перечень, на странице есть
  оговорка; сверить с фактической номенклатурой склада.
- Неподтверждённые данные (год основания, число клиентов, объём базы, средние сроки
  поставки, расчётный счёт, минимальная сумма заказа) намеренно **не опубликованы** —
  вместо них стоят блоки «Что пока не уточнено» (`/kontakty/`, `/o-kompanii/`).
- Единственный отзыв (Александр, 5 из 5 в 2ГИС) приведён как цитата; рейтинг в
  разметку не добавлен, потому что одна оценка рейтингом не является.
